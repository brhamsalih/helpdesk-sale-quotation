# Helpdesk Sale Quotation

## Overview

This module extends OCA Helpdesk Management by allowing users to create a Sales Quotation directly from a Helpdesk Ticket.

## Features

- Add quotation fields to Helpdesk Tickets.
- Auto-fill Unit of Measure and Unit Price from the selected product.
- Create Sales Quotation from a Helpdesk Ticket.
- Automatically create a Sales Order Line.
- Link the quotation back to the Helpdesk Ticket.
- Prevent duplicate quotation creation.

## Dependencies

- helpdesk_mgmt
- sale

## Tested on

- Odoo 19
- PostgreSQL
- Ubuntu Server
